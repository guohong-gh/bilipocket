# Product

## Platform

desktop (Windows, Tauri 2 + WebView2)

## Users

- 主要用户：在 Windows 桌面上保存自己拥有版权或已获授权视频的哔哩哔哩用户；他们习惯在浏览器里收集链接，再交给本地下载工具处理。
- 当前开发版同时供产品与界面评审者体验完整流程；桌面模式使用真实引擎与用户授权账号，浏览器 mock 模式只用于界面开发。

## Product Purpose

BiliPocket 是一个本地优先的哔哩哔哩视频下载器桌面应用。它实现“粘贴链接 → 真实解析 → 选择清晰度 → 本地引擎下载 → 历史回看”的完整流程。v0.9.0 为真实引擎 Beta（个人本地使用）：yt-dlp/ffmpeg sidecar、SQLite 队列、扫码登录与真实文件落盘已接入；个人使用不要求代码签名、自动更新端点或托管 CI；公开分发时可另行配置。

## Positioning

把“本地优先、真实可验证、合规边界”放在下载器体验的中心：界面说明真实引擎、网络访问与授权边界，下载文件写入用户选择的目录，同时用真实桌面能力（窗口、通知、托盘、目录选择）支撑可信度。

## Operating Context

- Tauri 2 + WebView2 桌面应用，目标平台 Windows；最小窗口 1040×700，默认 1280×780。
- 运行时仅在解析、登录验证、下载与封面缓存时访问哔哩哔哩；封面经 Rust 缓存后由本地 asset 协议加载，WebView 不直接加载远程图片；不加载外部字体或 CDN，不上传本地记录。
- 队列、历史与设置保存在本机 SQLite；下载进度来自本地 yt-dlp 进程。安装版账号凭据保存在 Windows 凭据库，便携版使用解压目录内的 DPAPI 加密会话文件。
- 应用覆盖下载、队列、历史、设置、关于与合规五个页面，以及窗口控制、托盘、系统通知、目录选择与打开目录等桌面能力。安装版卸载会清除应用数据、WebView2 数据、Windows 凭据和自启项；便携版把全部运行数据放在解压目录的 `app-data/`，删除目录即无 C 盘应用残留。

## Capabilities and Constraints

- 已实现：链接/BV/av/b23 解析、真实 yt-dlp probe、B 站 `support_formats` 清晰度矩阵与当前会话权限、扫码登录/会话校验与真实账号权限、字幕/弹幕 sidecar 与结果页单独下载、每视频独立文件夹、真实下载队列（暂停/继续/取消/重试/并发/限速/断点续传）、取消时可选删除临时文件、进行中/已完成/已取消失败分组、SQLite 历史搜索/再下载/文件丢失状态、封面本地缓存、脱敏诊断导出、主题/并发/默认清晰度/文件名模板/目录/通知/托盘/开机自启设置、解析默认弹幕/字幕偏好、键盘焦点管理与减少动效支持。
- 清晰度与账号权限来自真实解析和用户自己的登录会话；不实现会员/付费内容绕过、DRM 破解或风控规避。
- 弹幕类型计数与字幕轨道来自真实解析；可随视频下载，也可单独下载到同一视频文件夹；下载时写入过滤后的 XML/SRT sidecar；附加内容写入失败会在任务/历史中显示警告。仍不支持 DRM、付费墙或批量抓取。
- 明确不做：会员/付费内容绕过、DRM 破解、批量爬取、平台风控规避、代理池或账号共享。
- 技术约束：原生 HTML/CSS/ES Modules、无前端构建器、无框架、无外部运行时依赖；Tauri CSP 禁止外部脚本与字体；写入只发生在用户选择的下载目录与应用数据目录，打开/定位命令会先校验路径位于上述根目录内。
- 文案使用简体中文；真实数据、引擎错误、账号权限和授权边界必须清楚标注，不能暗示官方隶属关系。

## Brand Commitments

- 产品名 BiliPocket；与哔哩哔哩官方无隶属关系；浏览器 mock 模式示例为虚构，真实模式数据来自哔哩哔哩。
- 合规提示是产品的一部分，不能为了视觉或营销弱化。
- 用户已确认的视觉约束（2026-11-01）：浅色优先、简约、去掉霓虹/发光/渐变和无意义的卡片堆叠；设置页使用扁平描边的语义卡片与 720px 单列布局，B 站粉只用于操作、选中和活动状态，不使用二次元贴纸。
- 保留现有 Tauri 应用图标与 mock 模式四张虚构封面；页面内品牌可以使用文字字标与克制的强调色。

## Evidence on Hand

- mock 模式保留四条虚构视频、四张本地 SVG 封面与种子数据，位于 `dev/mock-store.js`、`dev/demo-data.js` 与 `dev/assets/covers/*.svg`；真实模式使用网络解析和 SQLite。
- 无真实用户评价、客户案例、价格、下载速度、容量或平台指标；未来工作不得编造这些事实。
- 真实桌面能力来自 `src-tauri/src/lib.rs` 与 Tauri 配置；前端视觉验证可对照 README 中的交互说明。

## Product Principles

1. **真实要诚实**：真实引擎、网络访问、账号权限、错误和未完成能力都必须在界面上可被识别；浏览器 mock 只用于开发。
2. **队列要可读**：用户必须一眼看出任务当前状态、进度、剩余时间以及下一步能做什么。
3. **本地优先**：队列、历史、设置和下载文件留在本机；只把必要的解析/登录请求发送给哔哩哔哩，不上传本地记录。
4. **桌面工具先完成任务**：交互可预测、键盘可用、动效克制，视觉不为装饰牺牲效率。
5. **合规是边界而非脚注**：下载授权、内容类型和不支持的能力要被清楚说明。

## Accessibility & Inclusion

- 全流程键盘可操作，可见焦点，弹窗焦点陷阱与 Esc/取消默认，路由切换后焦点落在页面标题。
- 支持减少动效偏好；正文不使用低于 12px 的字号；状态不能只靠颜色区分。
- 中文界面，使用系统字体以适配 Windows 桌面与 200% 缩放。
